## Readme Guidelines--Happens to be this Readme's First Topic

This is the first topic of this particular readme file; the topics of your
readme files will be different, of course.

Here are some guidelines:

- Name the file `README.markdown`.

- Capitalize headings using these capitalization rules
<http://en.wikibooks.org/wiki/Basic_Book_Design/Capitalizing_Words_in_Titles>.

- Limit lines to 80 columns, unless they're lines of code or links (URL or image
links). 

- Use the
[MultiMarkdown](http://fletcher.github.com/peg-multimarkdown/mmd-manual.pdf)
format for Markdown. It makes the documentation easier to convert to official
docs, which use MultiMarkdown.

- To produce pre-formatted blocks, indent using four spaces. 

Here's a preformatted block:

    Here's a line of code.
    Here's another line of code.

End your sections with text; if another topic section follows, transition to the
next topic by stating something like this:

Next, is a another topic about ...
